# 001 — Wire mocha and CI to a repo with no tests

## Build order

1. Add devDependencies: `mocha`, `chai`, `@types/mocha`, `@types/chai`,
   `ts-node` (this repo runs TS via `tsx` for dev, not `ts-node` — added
   as a test-only tool to match the uniform mocha wiring used across
   this sweep, without disturbing the `tsx` dev workflow).
2. Add `test/placeholder.spec.ts`.
3. Add an npm `"test"` script: mocha over `test/**/*.spec.ts` via
   `ts-node/register`.
4. Add `.github/workflows/test.yml`: PR + push to `main` (default
   branch), Node 22, `npm ci`, `npm test`.
5. Verify `npm test` green locally.

## Blast radius

1. Other call sites: none — new file.
2. `core/` submodule: none in this repo.
3. CLAUDE.md contracts: this repo owns `GET /help`, `/blog`, `/search`,
   `/metadata` REST endpoints (consumed by main-app RAG and
   public-frontend). Nothing here touches those routes or their JSON
   shape — devDependency/CI/test file changes only.
4. Other tests: none exist yet.
